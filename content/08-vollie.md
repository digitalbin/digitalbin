# Vollie

## A simplified, slim reader for reddit.com

This is a project made by me (dev) and my friend [MickeTusen](https://www.linkedin.com/in/mikael-weidenhielm-a71298139) (design) out of boredom.

It uses the unofficial reddit JSON API and is built in Svelte.
